# Scenarios

Versioned scenario configuration files (structured, schema-validated data) will live here, grouped
by specialization:

```
scenarios/
  international_trade/
  translation/
  infocom/
```

Nothing is here yet. The scenario schema is designed and implemented in **Phase 3** (core simulation
engine), and the first real scenario, *Delayed International Shipment*, arrives in **Phase 6**.

All companies, people and transactions in scenarios must be fictional. Professional facts and
assessment criteria must be reviewed by a subject specialist before they are treated as
authoritative (see `docs/LIMITATIONS.md`).
